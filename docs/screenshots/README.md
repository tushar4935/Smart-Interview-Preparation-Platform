# Preview assets

The README currently uses **stylized SVG previews** (`dashboard.svg`, `session.svg`, `analytics.svg`) so it looks complete without a browser. They illustrate the real screens — the live app does exactly this.

## Swapping in real screenshots (recommended for a portfolio)

Real captures are stronger than mockups. To replace them:

1. Open the [live app](https://smart-interview-preparation-platfor-theta.vercel.app) and log in with `demo@example.com` / `demo123`.
2. Capture each screen (macOS: `Cmd+Shift+4`, then drag) and save as PNG, ~1400px wide:
   - `dashboard.png` — dashboard with charts
   - `session.png` — interview session showing AI feedback (score, strengths, improvements)
   - `analytics.png` — analytics page with weak-area detection
   - `resume.png` — "practice from my resume" flow with detected skills
   - `admin.png` — admin panel
   - `demo.gif` — short screen recording of a full interview + AI feedback
3. In `README.md`, point the image links at your new `.png` / `.gif` files (replace the `.svg` references under **A look inside**).
